# 布丁课程表

一个单文件的课程表 + 出勤日历 + 月度统计网页，手机和电脑都能用。

## 功能

- **课程表**：按星期展示每日课程，自动标记「进行中」「即将开始」
- **日历**：月历视图，用颜色点显示每天每节课的出勤状态；过去的日期自动记为「已上课」
- **统计**：按月统计每门课的计划课时、已上课、请假、出勤率，含堆叠条形图
- **中英文切换**：右上角按钮切换，偏好保存在本地

## 使用

直接用浏览器打开 `index.html` 即可，无需构建、无依赖。

## 数据

课程数据和请假/补课记录写在 `index.html` 里的 `COURSE_DATA` 常量中：

```js
const COURSE_DATA = {
  courses: [ /* 课程列表 */ ],
  exceptions: [ /* 请假、补课等异常记录 */ ]
};
```

出勤状态保存在浏览器 localStorage（键名 `attendanceData`），语言偏好保存在 `lang`。
